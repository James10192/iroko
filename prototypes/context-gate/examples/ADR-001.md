# ADR-001: Keep CRM provider SDKs out of the core

Status: Accepted (EXAMPLE ONLY)

Context: This hypothetical SaaS supports multiple CRMs through an existing
ContactProvider interface. A direct provider SDK import in src/core would
couple the business logic to one vendor.

Decision: Put each vendor integration behind the ContactProvider interface.
Do not introduce vendor-specific imports in src/core. Do not invent a new
plugin framework when the existing adapter contract is sufficient.

Verification: Provider-independent core dependencies, existing contract
tests, and a deterministic forbidden-import check.

This ADR is fictional. Each real project must approve its own decisions.
